# Bin2Dec - Binary to Decimal Converter

A simple, real-time Binary to Decimal converter built as my first individual web project. This tool allows users to enter a binary string (up to 32 bits) and see the decimal equivalent instantly, along with the mathematical breakdown of the conversion.

Check out the live application here:[https://adheesha2004.github.io/bin2dec-converter/]

This project was inspired by the **App Ideas Collection** by [Florin Pop](https://github.com/florinpop17/app-ideas). 

Features
- **Real-time Conversion:** Results update instantly as you type.
- **Input Validation:** Restricts input to 0s and 1s only using Regular Expressions.
- **Educational Formula Box:** Shows the step-by-step mathematical breakdown 
- **Responsive Design:** A clean UI that works on both desktop and mobile.

 Built With
- **HTML5** - Semantic structure
- **CSS3** - Custom styling and layout
- **JavaScript** - Logic, validation, and DOM manipulation

 What I Learned
As my first solo project, this was a huge learning milestone. I focused on:
1. **DOM Manipulation:** Using event listeners to capture and respond to user input in real-time.
2. **Mathematical Logic:** Mapping string indices to positional powers of 2.
3. **Regex Validation:** Ensuring data integrity by filtering out invalid characters immediately.
